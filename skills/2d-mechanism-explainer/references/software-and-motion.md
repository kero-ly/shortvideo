# 软件与动作选择

下面列的是可完成相应技法的软件，不能据此反推某条参考片实际使用的软件。

| 路线 | 擅长 | 限制/工程角色 |
|---|---|---|
| Illustrator/Inkscape＋After Effects | 分层矢量、路径流动、遮罩、局部形变、标题和镜头合成 | AE商业软件；Linux生产主机不直接支持原生AE，需要解决执行主机约束 |
| Moho | 二维骨骼、网格变形、拟人器官/胎儿表演 | 复杂绑定更方便；本工程未验证软件与导出链路 |
| Adobe Animate | 矢量角色、补间与逐帧动作 | 适合反复表演；不自动提供医学结构正确性 |
| Blender Grease Pencil/二维平面 | 二维绘制、绑定、必要的空间层次 | 本工程配置了Blender路径，专用二维工作流未验证；不必把二维机制强行做成3D |
| SVG＋React/Remotion | 可编辑结构、确定性路径/粒子、逐帧时间控制、批量修订 | 推荐沿用已有引擎；器官形变/绑定需真实实现，SVG不是自动绑定系统 |
| 剪映/DaVinci Resolve | 导入动画、剪辑、配音、字幕及最终包装 | 可做简单关键帧；复杂解剖形变和连续流动更适合在动画工具中完成 |

## 从画面拆解技法

| 画面需求 | 资产与运动设计 | 主要检查 |
|---|---|---|
| 呼吸、器官受挤压 | 局部轮廓/网格变形；器官外形、连接和背景分层 | 连接保持、变形幅度、邻近结构关系 |
| 管内血细胞移动 | 细胞实例＋中心路径＋相位循环＋管壁遮罩 | 流向、速度、密度、边界、接缝 |
| 胎儿抬手、器官做表情 | 肢体与表情分层；关节关键帧或骨骼/逐帧 | 关节不脱落、表情一致、没有意外穿插 |
| 全身到局部剖面 | 共享结构锚点、坐标变换、细节逐级显现 | 位置对应、颜色含义、镜头前后连续 |
