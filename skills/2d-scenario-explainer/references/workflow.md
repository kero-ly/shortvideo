# 制作流程与共用能力

| 阶段 | 输入 / 工具 | 输出与进入下一阶段的条件 |
|---|---|---|
| 前期 | 用户 brief、可靠事实来源、风格规范 | PREPRODUCTION.md、逐镜 prompt 草稿；先做有限角色探索，展示实际图片与完整方案后确认整期 |
| 角色 | 选定图片 skill；目前已验证 openlux-gpt-image | 候选单人母版一张、设定表一张；核对实际尺寸、成年观感、角色识别点；展示后由用户确认角色及整期方案 |
| 首帧 | 用同一母版编辑每镜参考图；先做代表镜头 | references/character 与 references/shots；身份、手与道具、动作起点、留白通过审核 |
| 视频试跑 | 220 的 ComfyUI / MiniMax H3；capabilities/video-generation/h3_comfy.py | 单镜原片、完整 workflow / seed / 输入 hash / prompt / task ID；实际动作通过审核后再批量 |
| 视频批量 | 逐镜串行提交，GPU 锁与队列检查 | 各自唯一 runs；原片技术检查、抽帧审核、接受/拒绝与原因记录 |
| 声音 | capabilities/narration/indextts2.py 或用户选定配音工具；有来源的配乐 | narration / mix、真实音频时长、字幕时间线；不默认沿用案例测试声线 |
| 合成样片 | FFmpeg 裁切时间；Remotion 使用真实视频和本期图文 | 唯一合成 run、props、低清样片；检查标题/字幕/卡片与动作关系、口播同步 |
| 最终输出 | 220 Remotion + FFmpeg / ffprobe | 正式视频、封面、SRT、QA、来源和 SHA256 交付清单 |

## 图片与模型调用

调用图片 provider 前读取用户指定的当前 SKILL.md，使用其 helper 与私有配置；不复制密钥到仓库。OpenLux 例通过本地 helper 调用 gpt-image-2 编辑，H3 消费同步到 220 的单镜首帧。图片服务异常先报告，不能静默改 provider。付费请求无自动重复提交；超时要保留结果不确定性，先恢复/查询已有任务。

实际返回尺寸可能与请求不同，记录原始文件尺寸与 SHA256。不覆盖旧图。每镜只生成一张独立首帧，不生成拼图；后续镜头仍参考角色母版，不以已变脸的画面继续传递。

H3 当前资源由 configs/resources.json 指向 220 本机 ComfyUI；提交前检查服务、队列、GPU 与锁，不停止共享任务。已验证原生 576×1024 / 24fps，长度遵守模型 17k+5 约束，分辨率遵守节点要求；新服务/模型重新实测。最终 1080×1920 是合成/放大，不能称为原生高清生成。

大多数情境可以 Turbo8 起步；不是质量保证。baseline20 可用于明确失败镜头的有限返修。本期第10镜案例说明：长串“不要气泡/文字”不保证遵循，简短正向动作和更高质量路线可能有效。每镜一个主要动作、一个轻微运镜；不要求短镜跨多个地点。模型生成的中文、医学数字和检测结果不进入关键信息，改用后期图文。

## 声音、时间线与画面

以旁白真实时长建立 scene start/frames 与字幕，不依靠强行加速凑时长。模型帧数向上取整后裁切；延长尾帧只用于少量阅读时间并记录，不能用长冻结掩盖不足。模型原生音频默认不参与这类旁白科普。口型动作未专门同步时不要声称口型一致。

母版→首帧→视频均有版本和哈希。只有被接受的原片进入合成。新主题的版式、信息卡、旁白路径、镜头数必须来自该期数据；现有案例脚本要先适配，禁止只是改标题继续播旧音轨或旧医学卡。

## 失败与恢复

- SSH 异常：马上通知，停止服务器阶段；不在本地构建视频，不自行切换服务器。
- H3 已提交但轮询断开：查原 run 的 status / history / task ID；使用客户端 --resume-job 恢复，不另发 POST。已有轮询器与锁先检查。
- 参考图不合格：修参考图再生成该镜；视频不合格：保留失败文件与原因，只修该镜。
- 同一镜头最多自行执行两次保持方案含义的返修；仍失败就展示问题与修法讨论。需要换角色、镜头意图或工具路线时不等到次数用完，先讨论。
- 不删除共享模型、服务或别人的任务；不以技术成功替代视觉通过。

## QA 与交付

内容：核对事实/来源、行动建议与适用条件；健康主题不能仅凭症状诊断，按主题具体核查，早孕案例不能变成所有健康视频的固定免责声明。

画面：人物身份/衣着/成人比例、肢体与物件、动作达意、无多余人物/文字/道具；抽帧包含首中尾和动作关键点，发现异常扩大检查。合成检查每镜、卡片阅读时间、脸/手遮挡、平台界面安全区。

声音：旁白自然、字音准确、音乐不过度遮盖；实际听审后记录结论。字幕检查文本与声轨对应、连续时间线、总时长一致。

技术：全片解码、宽高/帧率/帧数/时长、H.264 yuv420p、AAC 48kHz 双声道（平台有不同要求时按其要求）；检查黑帧、响度与峰值。默认可接受 -19 至 -13 LUFS、真峰值 ≤ -1 dBTP。保留探测输出和检查日志，自动通过不代表内容/视觉/听审全部通过。

交付到 deliveries/<run-id>/：MP4、封面、SRT、时间线、镜头来源索引、QA、manifest。下载到本地核对 SHA256 再预览。视频和图片不入 Git；源码与文本记录按 docs/workspace-layout.md 同步，两端存在未提交文件先备份检查，禁止覆盖。
