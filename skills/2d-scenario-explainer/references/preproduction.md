# 前期方案与确认记录

写入 `projects/<episode-id>/PREPRODUCTION.md`，用下面结构组织具体内容：

1. **版本与状态**：draft / character_review_pending / character_approved / storyboard_review_pending / production_approved / revision_required；分别记录角色与整期的确认范围、对话依据。每次实质变更递增版本并重新确认受影响部分。
2. **内容 brief**：主题、受众、核心观点、看完后应理解/采取的行动、时长与画幅、参考风格、事实来源与待核实点。记录风格 preset ID、版本、画面类型/色调/场景/表达方式，以及本期语气或配色等覆盖项。
3. **角色母版设计**：年龄感、脸型/发型/体型、服装与配色、线条和光影、比例、明确不希望出现的元素；有已有资产时链接真实参考图。
4. **角色设定计划**：需要哪些角度与表情，母版如何保持一致。母版是单人参考，设定表用于审核，不把多人拼图送入图生视频。
5. **完整旁白**：按镜头列出真实可读文案、屏幕标题/字幕/卡片；事实与推测分开，避免绝对化、夸张诊断或靠焦虑吸引观看。
6. **分镜表**：镜头 ID、目的、首帧内容与构图、人物动作、运镜、预计秒数、旁白、屏幕文字、参考图来源/生成计划、图片 prompt、视频 prompt、工具与模型。新方案即使还没有图片也写清图像计划，不把未生成路径说成现有素材。
7. **制作路线**：每镜用图片编辑 + H3、Remotion 信息图或建模的理由；建模只有内容需要空间/机械准确性时使用。指出工具实测状态、输入输出、预算/请求数量、原生尺寸与交付尺寸、声音与音乐来源、困难和候选替代方案。
8. **验收目标**：内容准确、角色一致、动作达意、图文可读、旁白自然、字幕同步；标明发布或内部审阅。
9. **角色样张**：默认先生成一张单人母版和一张设定表供实际看图讨论，记录为候选；与完整方案一起展示。角色探索授权不代表后续视频生产批准。
10. **场景与物品设定**：列出场景ID、布局、色板、家具和关键道具，以及哪些镜头共用；每镜首帧包含完整情境与动作起点，不用空背景母版代替。
11. **全分镜图文审阅包**：角色方向确认后完成全部参考帧，以镜头ID逐一展示实际图片、版本/路径、中文旁白、屏幕文字、预计秒数、动作、运镜及工具/模型路线。总览用于比较，逐镜图应可放大检查；准确文字后期叠加。未完成素材明确列为缺项，不能把prompt当作参考帧。
12. **讨论与制作批准**：全部图文完成后统一讨论并确认版本，再启动配音、H3、建模、剪辑和渲染。已授权全部参考帧时不在三张样张后再问许可。

确认可记录为：“方案 v2及分镜图文包v2；用户已看过全部参考帧和中文文案，明确同意此版角色、分镜和工具路线；允许执行整期制作”。不能把一般工具授权或此前不同版本的批准复制到本版。

用户另行指定样张范围时记录为：“仅允许角色母版/三镜参考图探索；其余仍待确认”。交付样张后回到讨论阶段。以后已确认的母版可沿用，但本期完整分镜图文包仍需确认。
