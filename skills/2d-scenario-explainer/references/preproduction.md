# 前期方案与确认记录

写入 `projects/<episode-id>/PREPRODUCTION.md`，用下面结构组织具体内容：

1. **版本与状态**：draft / awaiting_confirmation / approved / revision_required；确认范围、对话依据。每次实质变更递增版本并重新确认受影响部分。
2. **内容 brief**：主题、受众、核心观点、看完后应理解/采取的行动、时长与画幅、参考风格、事实来源与待核实点。记录风格 preset ID、版本、画面类型/色调/场景/表达方式，以及本期语气或配色等覆盖项。
3. **角色母版设计**：年龄感、脸型/发型/体型、服装与配色、线条和光影、比例、明确不希望出现的元素；有已有资产时链接真实参考图。
4. **角色设定计划**：需要哪些角度与表情，母版如何保持一致。母版是单人参考，设定表用于审核，不把多人拼图送入图生视频。
5. **完整旁白**：按镜头列出真实可读文案、屏幕标题/字幕/卡片；事实与推测分开，避免绝对化、夸张诊断或靠焦虑吸引观看。
6. **分镜表**：镜头 ID、目的、首帧内容与构图、人物动作、运镜、预计秒数、旁白、屏幕文字、参考图来源/生成计划、图片 prompt、视频 prompt、工具与模型。新方案即使还没有图片也写清图像计划，不把未生成路径说成现有素材。
7. **制作路线**：每镜用图片编辑 + H3、Remotion 信息图或建模的理由；建模只有内容需要空间/机械准确性时使用。指出工具实测状态、输入输出、预算/请求数量、原生尺寸与交付尺寸、声音与音乐来源、困难和候选替代方案。
8. **验收目标**：内容准确、角色一致、动作达意、图文可读、旁白自然、字幕同步；标明发布或内部审阅。
9. **讨论问题**：只提出真正影响方案的取舍。展示方案后邀请用户修改并确认；在明确确认前不启动素材制作。

确认可记录为：“方案 v2；用户在当前对话明确同意此版角色、分镜和工具路线；允许执行整期制作”。不能把一般工具授权或此前不同版本的批准复制到本版。

样张例外记录为：“仅允许角色母版/三镜参考图探索；其余仍待确认”。交付样张后回到讨论阶段。以后已确认的母版可沿用，但本期剧情和工具计划仍需确认。
