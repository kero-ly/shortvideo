# 奶油绘本科普：2D 绘本动画 · 奶油暖彩 · 生活情境清单科普

选择“奶油绘本科普”、本期早孕成片风格或 preset `2d-storybook-cream-warm-daily-list-explainer@2` 时读取。参数源为 styles/presets/2d-storybook-cream-warm-daily-list-explainer.json及其components；不要把旧项目脚本当作通用生成器。

## 视觉与表现

圆脸、简化五官、略大头但明确成年的人物；柔和棕线、平涂轻阴影、少量纸感。居家布景以奶油白、浅木杏色和浅蓝为主，画面明亮、低饱和；高亮黄只用于后期标题。每个知识点用一个日常情境承载，动作克制，固定机位或轻推，不依靠强口型表演。

场景要有家具、关键物品、前后景和人物与道具关系。同空间先设布局和色板，再复用场景参考；完整首帧包含背景、物品、人物和动作起点，角色白底母版只承担身份标准。准确汉字与医学数字交给后期。

## 成片排版默认值

以下是1080×1920画布的起点，不是所有主题的硬编码：

|---|---|

新标题更长时重排字号/换行与留白，不能直接挤出画框；手机尺度和平台UI遮挡单独检查。不要把“8个信号”、13镜或本期提示文案写死为风格要求。旁白自然友好；轻快、低音量的无歌词配乐为可覆盖默认，受众、语气和时长按内容设计。

## 工具路线与复用边界

角色母版＋设定表 → 用户看图确认 → 每镜完整情境参考帧＋中文文案＋动作/运镜prompt → 网页统一确认 → TTS实际时长与H3逐镜生成 → 字幕对齐/融合 → Remotion＋FFmpeg低清带声样片 → 用户确认或明确要求完成 → 正式尺寸与QA。

图片用用户指定的当前图像skill（案例为OpenLux GPT Image 2）；H3在220运行，TTS案例为IndexTTS2；Python用uv。建模只在内容需要几何/空间准确性时另行提出，不为了流程齐全添加Blender。连通性问题马上报告，不转本地生产。

案例入口：projects/early_pregnancy_signs_storybook_02/PRODUCTION.md；最终证据 review/final-v4/{qa,manifest}.json。13镜原生576×1024，最终1080×1920；完整链路与技术QA已验证，完整人工听审与声线公开使用权仍未核实。

可参考该项目 build_review.py、review_fused_captions.py、finalize_approved_title.py 的结构，但这些脚本有早孕内容、旧run、固定13镜/1910帧和资源路径。新期先替换为本期数据并核对所有依赖；JSON目前是代理读取的规范，并非Remotion自动加载配置。重用方法，不重用旧主题文案、角色身份、字幕时码或音轨。
