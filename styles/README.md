# 风格分类与命名

用“大类 + 多维组合预设”组织，避免为所有组合建立重复 skill。风格回答画面看起来是什么、内容怎样呈现；主题、语气与工具另行记录。

## 命名规则

展示名称：**画面类型 · 色调组合 · 场景与表达方式**。名称可以省略不影响区分的细节；完整属性与搜索标签保存在预设 JSON。明亮是亮度，可爱是造型/气质，两者不当作互斥色调；阴暗也要拆成低亮度、冷暖与情绪，减少歧义。

| 维度 | 本期取值 | 其他可能取值（候选，不代表已有能力） |
|---|---|---|
| 画面类型 | 2D 手绘动画 | 真人实拍、2D 扁平动画、3D 卡通、3D 写实、混合媒介 |
| 绘制细节 | 柔和线稿、轻赛璐璐阴影、轻纸感 | 矢量平涂、水彩、像素、写实材质 |
| 色调 | 暖色 / 明亮 / 低饱和 | 冷色 / 暗调 / 高饱和、黑白 / 高对比 |
| 场景 | 生活居家 | 工作职场、校园、自然、实验室、机械剖面、抽象空间 |
| 表达方式 | 人物情境科普 | 剧情叙事、口播讲解、信息图演示、素材剪辑、原理模拟 |
| 语气（独立属性） | 温柔陪伴 | 幽默、客观、悬疑、激励 |
| 节奏（独立属性） | 舒缓适中 | 快节奏、慢节奏 |

母婴、睡眠、机械是主题标签；H3、Blender、Remotion 是实现工具，不进入视觉风格名称。可爱/严肃等气质可作为补充标签，必须配合明确的人物造型与表达规范。

当前登记两个预设：上面的暖色手绘动画已有内部审阅案例；新增的 [奶油绘本科普](2d-handdrawn/cream-warm-storybook-list-explainer.json) 是待制作验证的草案，完整名称为“2D 绘本插画 · 奶油暖彩 · 生活情境清单科普”，ID 为 `2d-storybook-cream-warm-daily-list-explainer@1`。它复用同一情境科普 skill，以圆脸、略大头成人形象、奶油暖彩和清单标题覆盖默认视觉参数。首期方案见 `projects/early_pregnancy_signs_storybook_02/PREPRODUCTION.md`，尚待前期确认。

未来可按需要增加同大类的“冷色暗调 · 悬疑叙事”或“明亮高饱和 · 趣味科普”，这些目前只是命名示例，尚未实现或验证。真人实拍、3D 卡通等建立同级大类，避免嵌套到手绘动画之下。

风格预设保存视觉参数和标签；skill 保存制作过程与工具路由；项目保存主题、事实、角色、分镜及本期覆盖项。修改配色/语气通常新增覆盖项或预设；切换到叙事/实拍/3D 等导致流程明显不同，再建立对应 skill，共用配音、素材、合成和 QA 能力。

## 搜索、引用与调整

可以说：“用 **2D 手绘动画 · 暖色明亮低饱和 · 生活情境科普** 做睡眠主题，语气客观一点，先给前期方案。”

也可以用稳定 ID `2d-handdrawn-warm-light-muted-daily-explainer@1` 引用。项目的 PREPRODUCTION.md 记录：

```json
{
  "style_preset": "2d-handdrawn-warm-light-muted-daily-explainer",
  "style_version": 1,
  "overrides": {"tone": "客观但友好"},
  "topic": "睡眠",
  "status": "awaiting_confirmation"
}
```

这些是规范与数据，尚未实现自动风格搜索器或预设加载引擎；代理读取它们准备方案。先做有限角色母版和设定图供看图讨论；用户确认角色与方案后才进入分镜素材与视频制作。
